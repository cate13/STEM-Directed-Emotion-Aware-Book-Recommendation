# STEM Directed - Emotion Aware - Book Recommendation 

# Classifier
The code used to train the classifier along with the .joblib file

# Implementation 
The implementation code. The two most important files are recommender.py and metrics.py. recommender.py creates the recomendations and metric.py evaulates the recomendations.

# LLM Code
The four files for generating the LLM based recomendations 

# Recomender_Helper
Contains the vector_helper.py file which has a variaty of methods used for recomendation and vector processing 

# STEM_Books
Contains the code for identifying STEM books by their categories and topics 

# Vectorizer
Contains the various classes used to turn book descriptions into emotion and STEM topic vectors

# data_exploring
Contains code to examine the dataset

# processed_data
Contains the book dataset organized by book, with readers and ratings attached, and the saved book vectors 

# recommendations 
Contains the recomendations generated by recommender.py

# stem_emotion_relation
Contains code and data for exploring the relationship between STEM topic preferences and emotional preferences 

# user_eval_sets
Contains the users organized into useable user sets for evaulation 








### Starting Data

The un-formatted book data comes from the [Book Crossing dataset](https://www.kaggle.com/datasets/somnambwl/bookcrossing-dataset)
